# Postiz local — Puterea Minții

Pornire:

```sh
./start-local.sh
```

Interfață: <http://127.0.0.1:4007>

Secretul JWT este păstrat în macOS Keychain sub serviciul
`com.putereamintii.postiz.local`; nu se salvează în repo sau `.env`.

Instanța locală este pentru PoC. Conectarea providerilor și publicarea externă rămân
dezactivate până la aplicațiile OAuth aprobate și canarii per platformă.
